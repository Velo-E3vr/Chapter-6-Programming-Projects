Function celsius(fahrenheit):

Compute: c = (5.0 / 9.0) * (fahrenheit - 32)

Return c

High-Level Pseudocode

Loop through a range of Fahrenheit temperatures

Convert each Fahrenheit value to Celsius using a separate function
