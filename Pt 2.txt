Set minAccidents = a1

Set safestRegion = "North" (matching a1)

Compare a2 to minAccidents

If a2 < minAccidents, update minAccidents = a2, safestRegion = "South"

Compare a3 to minAccidents

Compare a4 to minAccidents

Compare a5 to minAccidents

Print safestRegion and minAccidents
